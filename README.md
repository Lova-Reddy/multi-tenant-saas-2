
# Multi-Tenant SaaS Platform

## Overview
This project is a Multi-Tenant SaaS platform featuring:
- **Backend**: Node.js, Express, PostgreSQL, Sequelize.
- **Frontend**: React, Vite, Tailwind CSS.
- **Authentication**: JWT-based auth for Super Admins and Tenants.

## Setup Instructions

### Prerequisites
- Node.js
- PostgreSQL

### Installation
1. Navigate to the `server` directory and install dependencies:
   ```bash
   cd server
   npm install
   ```
2. Navigate to the `client` directory and install dependencies:
   ```bash
   cd client
   npm install
   ```

### Configuration
1. Setup your PostgreSQL database.
2. Update `server/.env` with your database credentials.

### Running the App
1. Start the backend: `npm start` (in `server/`)
2. Start the frontend: `npm run dev` (in `client/`)
